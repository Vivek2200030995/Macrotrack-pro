# MacroTrack Pro

A modern nutrition and macro tracking web application built using HTML, CSS, and JavaScript.

## Features
- Macro tracking
- Calories calculation
- Protein, carbs, fats tracking
- Smart food database
- Telugu & Indian foods support
- Responsive modern UI
- Daily goals tracking

## Technologies Used
- HTML
- CSS
- JavaScript
